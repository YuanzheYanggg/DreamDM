# RPG 主导演与 DM 分工 v4

用户本轮明确修正：选项和后果的逻辑完整性在 Astra 编写、发散、设计合流时负责；Jev 不再担任逐回合编剧审核员。既有故事文案和已完成旅程保留。

一项选择可以同时改变状态、触发预写支线、累计后续条件。合流是回到同一阶段，不是抹平状态、人物关系和条件。运行器只执行声明过的结果，严格校验资源、候选 ID、类型、概率和事务；这些执行校验不属于剧情语义审查。

Astra 开局生成完整可执行短篇，并在开局预算中自行复核世界规律、人物知识、各结果效果、失败退路、合流和伏笔。结构/审核失败留在准备阶段。后台草稿由 Astra 复核，只在未展示且来源状态仍适用时发布。Jev 不参与稿件出版审批。

Jev 每回合一次并行问题：风险行动用 Score 给坏/中/好分布，按单次运势结算；Choice 在确定档位内选完整后果包。每个条件后果附一个 Noul 评估未来覆盖不足、一个 Choice 指明是否资源下限/上限、缺失必要条件或路线变化不足。只消费实际选中后果的调度建议。不做一致性/冲突概率拦截，不为低分重抽。

主线重规划要有具体未来阶段和未覆盖需求；正常失败、可用补救路线、普通属性波动、想增加趣味都不构成重规划理由。调度信号与当前行动分开：当前结果先提交，极少数确有未覆盖状态的情况才排后台 Astra high 主线方案；当前版本将方案保存为 `mainline_proposal`，`applied:false`，不把普通文案修改冒充剧情图修复。已经写好的兜底路线仍可继续。各类配额和过去调用账本不变。

当前短篇固定图只能承载有限状态、渡鸦支线约定、入口条件和未来文案调整。此次实现分工和可追溯的重规划建议；不声称已完成 100 步动态节点图或新支线内容。完整动态主线的节点/边变更与编译是后续内容系统范围。

当前代码采用短篇固定覆盖契约：生命最低 1，钟顶必需借名簿，档案馆有免费值夜人退路；没有资源上限或必须新增的路线变化，因此强角色不会仅因太强而触发改写。`lastImpact` 和事件 receipt 记录状态、支线、条件与主线建议。低/中档文案修改仍可手动请求，不再每回合自动触发。
